# Documentation

The pages fall into four groups. **Reference pages** describe the system as it is now. **Method notes** record how the data and the evaluation were examined, and hold numbers measured on the real data. **Background notes** were written while planning, about the upstream projects and the hackathon; they describe plans and other projects, not this code. **Outreach drafts and the plan** are kept for the record, and are not documentation of what was built.

## Start here instead

- **Deciding whether it works?** [TESTING.md](../TESTING.md).
- **Want the argument and the results?** The [README](../README.md).
- **Want to know how it fits together?** [ARCHITECTURE.md](../ARCHITECTURE.md).
- **Changing the code with an agent?** [AGENTS.md](../AGENTS.md).
