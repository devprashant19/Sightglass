## 1. Submission package per round

- [ ] Link to the TimeNet PR (merged, or open and passing CI).
- [ ] Public `sightglass` repo with README: problem, results table, how to reproduce, limitations.
- [ ] Dashboard URL.
- [ ] 2–3 minute demo video.
- [ ] Model card: data, training, metrics, intended use, out-of-scope use, limitations, licences. Optionally weights on Hugging Face.
- [ ] X and LinkedIn post links.
- [ ] Submit at least 12 hours before the deadline; keep a copy of every answer in `docs/submissions/round-N.md`.

## 2. README structure

1. One-line description and a GIF of the explorer.
2. The problem, in three sentences.
3. Results table (generated by `scripts/make_readme_table.py`) with the pre-registration commit SHA.
4. How it works: the four-step pipeline and the architecture diagram.
5. Reproduce: `make data && make rationales && make baselines && make train && make eval && make export && make site`, with expected times and costs.
6. Limitations.
7. Licences: code, each dataset, each backbone.
8. Citation and acknowledgements (TimeNet, OpenTSLM, Nebius, dataset authors).

## 3. Model card (`MODEL_CARD.md`, also on Hugging Face)

- Model details: architecture, backbone, checkpoint lineage, version.
- Intended use: decision support for maintenance engineers on similar hydraulic rigs; **not** a safety system and not a replacement for inspection.
- Training data, evaluation data and splits.
- Metrics, including faithfulness, with CIs.
- Limitations: single lab rig, virtual sensors, artificial fault levels, small test sets.
- Ethical and safety notes: a wrong "healthy" verdict can delay maintenance; always check the cited evidence.

## 4. Demo video (about 2.5 minutes)

Record at 1080p, with captions burned in, so it works muted on social feeds.

| Time | Section | On screen |
|---|---|---|
| 0:00–0:20 | Problem | A pump starts leaking; the plant has no analyst; an alarm says "fault" but not why. |
| 0:20–0:40 | What we built | TimeNet dataset, fine-tuned OpenTSLM, physics-grounded explanations. Pipeline diagram. |
| 0:40–1:40 | Live explorer | Pick a cycle; show the diagnosis; hover numbers in the rationale to light up the sensor; show the verified ticks. Show one failure honestly. |
| 1:40–2:10 | Results | Accuracy vs baselines, then the faithfulness chart vs GPT-4o. |
| 2:10–2:30 | Next | Limitations; bearings, wind turbines, pooled model. Links. |

- [ ] Script written by day 12; recorded day 13; one re-take budget.
- [ ] Export a 15-second cut of the explorer moment for posts.
